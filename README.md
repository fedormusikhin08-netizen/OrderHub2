# OrderHub — учёт заказов интернет-магазина

Итоговый проект по контрольным точкам **КТ31–КТ39** («Коллекции, LINQ, перечислители и итераторы в C#»).

Консольное приложение, которое последовательно обрастает возможностями:
очередь и стек заказов, история на `LinkedList`, склад на `Dictionary`,
сортировка каталога, отчёты на LINQ, ленивые итераторы и собственная
коллекция `CircularBuffer<T>` с поддержкой `foreach`.

## Как собрать и запустить

```bash
dotnet build OrderHub.sln
dotnet run --project src/OrderHub
```

Требования: .NET SDK 8.0 или новее.

## Этапы проекта

| №  | КТ   | Тема                                      | Что появилось в проекте                    |
|----|------|-------------------------------------------|--------------------------------------------|
| 1  | КТ31 | `List<T>`, `Stack<T>`, `Queue<T>`         | очередь заказов, стек отмен, полный список |
| 2  | КТ32 | `LinkedList<T>`                           | история заказов клиента, `AddAfter`        |
| 3  | КТ33 | `Dictionary<TKey,TValue>`                 | склад: поступление, продажа, `TryGetValue` |
| 4  | КТ34 | `IComparable<T>`, `IComparer<T>`          | три способа сортировки каталога            |
| 5  | КТ35 | LINQ: базовые запросы                     | `Where → OrderBy → Select`, агрегаты       |
| 6  | КТ36 | LINQ: проекции и группировка              | сводка по категориям через `GroupBy`       |
| 7  | КТ37 | LINQ-запросы к коллекциям                 | `Join`, топ-3 клиентов через `Take`        |
| 8  | КТ38 | Перечислители и итераторы                 | ленивый генератор заказов `yield return`   |
| 9  | КТ39 | Пользовательские итераторы                | `CircularBuffer<T>` с `foreach` и `Reverse` |

## Управление

Приложение предлагает интерактивное меню из 12 пунктов (сценарий защиты)
и пункт «0» — полный прогон всех отчётов одной командой.
