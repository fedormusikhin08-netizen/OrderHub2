# Презентация запуска: OrderHub (КТ31–КТ39)

Слайд 1. **OrderHub — учёт заказов интернет-магазина**
Итоговый проект КТ31–КТ39. Консольное приложение .NET 8, репозиторий с девятью ветками этапов.

Слайд 2. **Как устроен проект**
`Domain` — заказы, товары, клиенты. `Services` — 5 сервисов по этапам. `Collections` — собственный `CircularBuffer<T>`. `Data` — начальные данные. `Program` — меню из 12 пунктов.

Слайд 3. **КТ31: List + Queue + Stack**
Список всех заказов, очередь обработки (FIFO, `Enqueue`/`Dequeue`), стек отмены (LIFO, `Push`/`Pop`). Проверка: 3 заказа → 2 обработано → в очереди остался Сидоров.

Слайд 4. **КТ32: LinkedList**
История клиента на узлах `Previous/Next`, вставка `AddAfter(current, …)`, безопасный поиск с проверкой узла на `null`.

Слайд 5. **КТ33: Dictionary**
Склад «название → количество»: поступление и продажа через `TryGetValue`, удаление `Remove` при нуле. Ни одного `KeyNotFoundException`.

Слайд 6. **КТ34: сортировки**
`IComparable<Product>` (по цене) + `NameComparer`/`PriceDescComparer` (`IComparer`) + лямбда `Comparison<T>` (по длине названия). Тип `Product` не меняется.

Слайд 7. **КТ35: базовый LINQ**
`Where → OrderBy → Select → ToList`, агрегаты `Count/Any/All/First`. Отложенное выполнение: смена порога не меняет код.

Слайд 8. **КТ36: GroupBy**
Сводка по категориям: `Count`, `Average` прямо на группе, проекция в `CategorySummary`, сортировка `OrderByDescending`.

Слайд 9. **КТ37: Join + Take**
Заказы ⋈ клиенты по имени, `GroupBy → Sum → OrderByDescending → Take(3)`: Петрова 76280 ₽, Иванов 25470 ₽, Кузнецова 21990 ₽.

Слайд 10. **КТ38: yield return**
Бесконечный генератор: после вызова — ни одной строки трассировки; `Take(5)` → ровно 5 заказов. `ToList()` без `Take` завис бы.

Слайд 11. **КТ39: CircularBuffer<T>**
Собственный `IEnumerable<T>`: `yield return` в `GetEnumerator`, явная реализация `IEnumerable.GetEnumerator`, обратный обход `Reverse()`. Ёмкость 3 → вывод 3,4,5 / 5,4,3.

Слайд 12. **Git и защита**
21 коммит, ветки `stage/31…stage/39`, слияния через PR, README, `.gitignore`, отчёт. Защита: прогон пунктов меню 1–12 с комментариями по этапам.
